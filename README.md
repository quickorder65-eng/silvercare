# SilverCare

Помощник для приёма лекарств, рассчитанный на пожилых людей. Никакой сборки и бэкенда: чистые HTML/CSS/JS файлы, которые работают прямо в браузере.

Проект состоит из двух частей:

- **`/` — сайт-презентация** (`index.html`, `landing.css`, `landing.js`, `assets/`): рассказывает о продукте — для жюри хакатона, будущих пользователей и их близких.
- **`/app` — само приложение** (`app/index.html`, `app/app.js`, `app/styles.css`): экран для пожилого человека — крупные кнопки, голос, вибрация, ничего лишнего.

Сайт-презентация никогда не показывает управление лекарствами напрямую — только кнопка **«Открыть приложение»**, которая ведёт в `/app`.

## Как запустить

Дважды щёлкните `index.html` — откроется сайт-презентация. Кнопка «Открыть приложение» откроет `app/index.html` — само приложение (данные хранятся в localStorage браузера).

Для локального сервера (например, чтобы открыть с телефона в той же сети):

```
python3 -m http.server 8080
```

и затем `http://localhost:8080` (или IP компьютера в локальной сети).

## Демонстрация на хакатоне

Сайт-презентация → «Открыть приложение» → онбординг (если ещё не пройден) → главный экран.

Полный сценарий приложения: первый запуск → анкета доступности → главный экран → напоминание → приём отмечен.

Чтобы не ждать реального времени приёма лекарства во время демо:

1. В приложении откройте **Настройки** (нижняя панель).
2. Нажмите **«Напомнить сейчас (демо)»** — сработает полноэкранное напоминание немедленно.

Там же есть кнопка **«Повторить настройку»** — снова пройти анкету доступности.

## Как устроено приложение (`/app`)

- `app/index.html` — точка входа приложения.
- `app/styles.css` — все стили приложения. Три параметра доступности (зрение / слух / управление кнопками) выставляются как `data-`атрибуты на `<html>` и управляют CSS-переменными: масштаб шрифта, контраст, минимальный размер кнопок, тени. Настройки комбинируются независимо друг от друга.
- `app/app.js` — вся логика на чистом JavaScript (без фреймворков и сборщиков): анкета первого запуска, экран часов с недельным календарём, планировщик напоминаний (проверяет время каждые 15 секунд и срабатывает не больше одного раза на слот), голосовые объявления через `SpeechSynthesis`, вибрация через `Vibration API`, упражнение для памяти, набор SVG-иконок вместо эмодзи.

Данные, которые сохраняются в localStorage:

- `silvercare_accessibility` — ответы анкеты доступности;
- `silvercare_medications` — список лекарств и отметки о приёме;
- `silvercare_onboarded` — пройдена ли анкета при первом запуске.

Список лекарств (образец для демо) задан в начале `app/app.js` в массиве `DEFAULT_MEDS`.

### Без прокрутки

Каждый экран приложения рассчитан так, чтобы полностью помещаться на одном экране телефона — даже в самом крупном режиме («почти не вижу» + «не слышу» + «мне трудно»). Размер текста и кнопок подстраивается под доступную высоту экрана (CSS `clamp()` с единицами `vh`), а не растёт бесконтрольно.

### Навигация и календарь

Внизу экрана — постоянная панель из 5 разделов (иконка + подпись на русском): **Сегодня**, **Лекарства**, **Напоминания**, **История**, **Настройки**. Активный раздел выделен не только цветом — фоном-плашкой и жирной подписью.

На вкладке «Сегодня» — недельный календарь: сегодняшний день обведён кружком, выбранный день отмечен фоном и полоской снизу (тоже не только цветом), стрелки листают неделю целиком. Выбор дня фильтрует список лекарств ниже. В крупном текстовом режиме календарь становится горизонтально прокручиваемым вместо уменьшения текста.

«Лекарства» — полный список препаратов. «Напоминания» — включение/выключение и изменение времени приёма. «История» — статусы приёма за последние 7 дней.

## Как устроен сайт-презентация (`/`)

- `index.html` — разметка сайта: шапка с навигацией, hero с макетом телефона, разделы «Почему SilverCare», «Как это работает», «Доступность», витрина возможностей, мультимодальные напоминания, галерея из трёх экранов приложения, финальный призыв к действию.
- `landing.css` — отдельная, более выразительная дизайн-система для маркетингового сайта (не для самого приложения): крупная типографика, тени, карточки, тёмная секция «Доступность».
- `landing.js` — мобильное меню и плавное появление секций при прокрутке.
- `assets/` — реальные скриншоты приложения, использованные в макетах телефонов на сайте.

Сайт полностью адаптивен (десктоп и мобильные экраны) и не содержит собственной логики лекарств — вся функциональность живёт в `/app`.

## Что уже реализовано из ТЗ

Сайт-презентация с отдельным входом в приложение; анкета доступности (зрение / слух / управление кнопками, экраны сохраняются и не показываются повторно); три комбинируемых адаптивных режима; главный экран-часы с ближайшим приёмом и недельным календарём; нижняя навигация из 5 разделов; полноэкранное напоминание с голосом и вибрацией (срабатывает один раз на слот, не повторяется); экран подтверждения с отменой; упражнение для памяти («какое сейчас время года» — с реальным текущим сезоном); настройки с повтором анкеты и демо-кнопкой; семантическая разметка с ARIA; видимый фокус для клавиатурной навигации; отсутствие критичной информации, переданной только цветом.
