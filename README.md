# SilverCare — MVP

Простое веб-приложение для напоминания о приёме лекарств, рассчитанное на пожилых людей. Никакой сборки и бэкенда не требуется: три файла, которые работают прямо в браузере.

## Как запустить

Проще всего — дважды щёлкнуть по файлу `index.html`. Он откроется в браузере по умолчанию, и приложение сразу заработает (все данные хранятся в localStorage браузера).

Если нужно открыть через локальный сервер (например, для тестирования на телефоне в той же сети), подойдёт любой статический сервер:

```
python3 -m http.server 8080
```

и затем открыть `http://localhost:8080` (или IP компьютера в локальной сети — с телефона).

## Демонстрация на хакатоне

Полный сценарий: первый запуск → анкета доступности → главный экран → напоминание → приём отмечен.

Чтобы не ждать реального времени приёма лекарства во время демо:

1. Откройте **⚙ Настройки** на главном экране.
2. Нажмите **«🔧 Показать напоминание сейчас (демо)»** — сработает полноэкранное напоминание немедленно.

Чтобы пройти анкету доступности заново, там же есть кнопка **«Повторить настройку»**.

## Как устроено приложение

- `index.html` — единственная точка входа.
- `styles.css` — все стили. Три параметра доступности (зрение / слух / управление кнопками) выставляются как `data-`атрибуты на `<html>` и управляют CSS-переменными: масштаб шрифта, контраст, минимальный размер кнопок. Настройки комбинируются независимо друг от друга.
- `app.js` — вся логика на чистом JavaScript (без фреймворков и сборщиков): анкета первого запуска, экран часов, планировщик напоминаний (проверяет время каждые 15 секунд), голосовые объявления через `SpeechSynthesis`, вибрация через `Vibration API` (с проверкой поддержки), упражнение для памяти.

Данные, которые сохраняются в localStorage:

- `silvercare_accessibility` — ответы анкеты доступности;
- `silvercare_medications` — список лекарств и отметки о приёме на сегодня;
- `silvercare_onboarded` — пройдена ли анкета при первом запуске.

Список лекарств (образец для демо) задан прямо в начале `app.js` в массиве `DEFAULT_MEDS` — там же можно поменять названия, дозировку и время приёма.

## Важно: без прокрутки

Каждый экран рассчитан так, чтобы полностью помещаться на одном экране телефона — даже в самом крупном режиме («почти не вижу» + «не слышу» + «мне трудно»). Листать вниз не нужно нигде: размер текста и кнопок подстраивается под доступную высоту экрана (через CSS `clamp()` с единицами `vh`), а не растёт бесконтрольно. Проверено на экранах от 360×640 до обычных смартфонов.

## Что уже реализовано из ТЗ

Анкета доступности (зрение / слух / управление кнопками, экраны сохраняются и не показываются повторно), три комбинируемых адаптивных режима, главный экран-часы с ближайшим приёмом, полноэкранное напоминание с голосом и вибрацией, экран подтверждения с отменой, упражнение для памяти («какое сейчас время года» — с реальным текущим сезоном), настройки с повтором анкеты и демо-кнопкой, семантическая разметка с ARIA, видимый фокус для клавиатурной навигации, отсутствие критичной информации, переданной только цветом.
